## 使用方式

首頁有每日五觀念、觀念小測驗、觀念搜尋、學習紀錄及本週學習挑戰。每次開啟或重新整理回首頁，個人紀錄與當日卡組仍保留。

- 每日五觀念：先選單元或隨機單元，按「開始學習」才顯示卡片，每輪五個不同觀念。首次有操作提示；點卡片看提問，每個觀念必須選「還不熟」或「已掌握」才自動前進。可用「上一個」回看；已自評卡片可再次前進，單純回看不累加複習次數。顯示第幾個觀念與細進度條，圖片可放大。學習途中可「更換單元」，回到原單元保留本輪卡組與進度。完成後可選「再學五個」重新選單元，或做三題測驗。
- 觀念小測驗：直接選單元作答三題，不必先學五個觀念。
- 觀念搜尋：搜尋所有單元的標題、說明、公式及問答。開啟結果可切換三種呈現；按「這張看完了」記錄一次複習。
- 狀態紀錄：學習紀錄分別列出「已掌握・自評」與「還不熟」，按單元分組，可原處展開及重新分類。已掌握是學生自評，非測驗通過；測驗答錯會轉回還不熟。舊版沒有自評的閱讀紀錄不自動列為已掌握。
- 還不熟：在學習紀錄依單元分組並顯示數量，點觀念標題即可原處展開完整卡片、切換三種呈現及查看自我提問；圖片可放大。「移出還不熟」取消標記，並可立即復原，不刪除教材或過往紀錄。標記或測驗答錯的觀念，之後會較常抽到。同觀念再次出現時，優先較少看過的呈現。
- 學習紀錄：本週日曆分別顯示「✓ 學習」（當天完成五個觀念的自評）與「✓ 測驗」（當天提交至少一題，不限定答對），兩者皆完成時同時顯示。另有學習天數、完成張數、複習次數、作答及答對次數。重複閱讀或提交答案會累加；只回看詳解不累加。
- 本週學習挑戰：自願以暱稱加入，切換讀卡／測驗排名，每週一臺灣時間00:00換週。

教材準備時會顯示提示；先點首頁入口，準備完成後會自動進入。全體統計在背景同步。

個人紀錄存在這個瀏覽器，不同裝置不會自動同步；清除瀏覽資料會移除紀錄。全體累積與排行榜使用已設定的 Google Apps Script 服務，採批次上傳與快取讀取；需要連網及正式網站環境。啟用與後端維護請見 `apps-script-counter/啟用說明.md`。舊版 `community-counter` 不需上傳。

## 這次更新 GitHub

本次改為自評後前進，新增已掌握／還不熟分類與互換功能。舊學習紀錄保留，回看不重複累加複習次數。只需替換網站根目錄的 `index.html`，圖片和 Apps Script 不用修改。

`physics-review.zip` 是完整網站及維護文件；`physics-review-update.zip` 只含本次的 HTML 和更新說明。若尚未上傳前次運動配圖修正，仍需將「運動卡片配圖修正」18張PNG加進原有 `images`。

## 維護檔案

- `CONTENT.json`：觀念、呈現、自我提問、測驗、來源與關聯。
- `IMAGE_SOURCES.json`：原圖的PDF頁次、裁切座標與尺寸。
- `CONTENT_REVIEW.md`：教學與物理核對、修正紀錄。
- `CARD_REVIEW.md`、`QUIZ_REVIEW.md`：完整文字、答案及逐項詳解，供教師審閱。
- `tools/rebuild.py`：將內容重新內嵌HTML。
- `tools/review_docs.py`：更新審閱文件。
- `tools/validate.py`：驗證資料結構、圖片、來源答案與部分數值，不取代內容審閱。

新增單元後依序執行上述三支Python工具，再以瀏覽器檢查。各單元至少需要五個觀念與三題來源可靠的測驗。教材不使用CDN，GitHub Pages不需建置。
