# 每天物理複習：觀念教學版

解壓縮後，直接雙擊 `index.html`，以 Chrome、Edge、Safari 等現代瀏覽器開啟。`images` 必須放在同一層。不需伺服器、安裝套件、上傳或網路。

本版有 19 個量子現象觀念、57 種教學呈現與 57 個對應自我提問。正面為整理後的標題、核心句、兩段說明、必要公式、講義示意圖、讀圖引導與適用條件；背面只檢查該卡的核心觀念，答案有明確理由。

圖片是三份講義的實際圖像，保留必要標示。文字與問題由本站重新整理，不是講義原段落或原題的截圖。三種呈現是同一觀念的三種教學角度，不保證三份來源每份各有一張適合的圖；缺乏合適圖、或原圖有誤導風險時會共用較適合的原圖，畫面始終標明實際圖源。

## 操作

- 選「量子現象」或「隨機單元」。目前只有量子現象。
- 每日五個不同觀念，以教學順序排列抽中的觀念；當日重新開啟保留卡組與位置。
- 點卡片的文字或空白處看提問，先想答案及理由，再按「看答案與理由」。點文字可回看說明。
- 往右滑下一張，往左滑上一張；也可用下方小箭頭或鍵盤方向鍵。
- 點圖可放大，放大視窗點兩下可進一步縮放。
- 不熟的觀念可標記「還不熟」，之後抽選權重為一般觀念的四倍。標記後不會當場替換今日五張。
- 同觀念再次抽到時，避開上次看過的呈現，優先安排較少看過的呈現。
- 背面收合的「相關觀念」可開啟完整觀念卡，不影響今日五張。
- 自我作答不自動評分。答案與理由都能說明才算理解，不能只看過就判定學會。

## 檔案與擴充

`index.html` 包含所有程式、樣式、內容，僅圖片是同資料夾內的本機檔案。網站執行時不讀取 JSON、不使用外部字型或 CDN。

- `CONTENT.json`：可維護的觀念、呈現、題目、答案、來源與關聯資料。
- `IMAGE_SOURCES.json`：每張圖的 PDF、檔案頁次、原頁比例座標和像素座標。
- `CONTENT_REVIEW.md`：教學問題、修正紀錄與逐觀念核對表。
- `CARD_REVIEW.md`：所有卡的完整文字、讀圖說明與問答，方便教師審閱。
- `tools/rebuild.py`：修改內容後重新內嵌。
- `tools/validate.py`：檢查結構、圖片存在、數值例題；不取代物理與教學審閱。

未來六單元可在 `CONTENT.json` 的 units 增加單元；每單元至少五個不同觀念。每個觀念定義一個學習目標，題目只測此目標，圖源須有明確版本與頁次。修改後執行 `python3 tools/rebuild.py`、`python3 tools/validate.py`，再開啟 HTML 審閱。

## 保存與發布

紀錄只保存在本機瀏覽器，不跨裝置同步；清除瀏覽器資料會移除紀錄。瀏覽器若不允許 `file://` 儲存，網頁會提醒，但內容仍可閱讀。本版使用獨立儲存鍵，不會把舊版不同編號的紀錄配到新卡。

可將本資料夾內容放在 GitHub repository 根目錄，用 GitHub Pages 的「Deploy from a branch」發布，不需建置。圖片仍有原講義的著作權，公開使用需有適當授權。本次沒有上傳或公開發布，也未附入原始完整 PDF。

本版依講義與外部教材核對並進行教學審閱；沒有以學生實測證明學習成效，也不宣稱零錯誤。所有內容與來源可在附帶審閱檔逐卡追查。
